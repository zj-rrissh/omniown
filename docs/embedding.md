# Embedding 文档

>
> 语义搜索（semantic-search / embed / embedding-provider-info）已由 `ai-search`（LLM → 搜索词 → FTS5）替代。
> 相关代码（`src/embedding.rs`、`src/embedding_worker.rs`）、CLI 命令和配置节（`[embedding]`、`[worker]`）已全部移除。
>

>
> 此文件保留为历史参考。
