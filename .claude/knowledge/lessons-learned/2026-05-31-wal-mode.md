# WAL 模式统一

## 问题

Prisma（DELETE journal 模式）和 rusqlite（WAL 模式）同时访问同一 SQLite 文件，SQLite 报 "disk I/O error"。

## 解决方案

Node.js 启动后立即执行 `PRAGMA journal_mode=WAL`（在 `prisma db push` 之后）。Rust 端 `db::init_database()` 也执行同一 PRAGMA 作为幂等保护。

## 注意事项

- WAL 模式会产生 `-wal` 和 `-shm` 辅助文件，需加入 .gitignore
- `prisma db push --skip-generate` 不改变 journal 模式
- 两个进程都需要在操作数据库前设置 WAL
